Why it's different

Transparent by construction

No bundler, no transpile, no minify — so what you review is exactly what runs in the browser. There's no dependency tree to audit and nothing hidden in a build artifact.

🚫

Zero dependencies

No node_modules, no transitive tree, no registry account that can be phished into your build. Nothing to hijack.
🛠️

No build step

Plain ES modules + standard DOM. Drop the folder in, import what you need, serve it. The files you write are the files that ship.
🔒

CSP-safe

No eval / new Function. Runs under a strict script-src 'self' — right for privileged admin tooling.
📦

Embeds anywhere

//go:embed the folder into a single backend binary, or serve it from any static host — even file://.
🔎

Verifiable

Pin a tag, read it, diff the next one — a real code review, not a version bump you hope is fine.
🎨

Themeable

One stylesheet per component, driven by a --pd-* token chain. Looks right with zero config; auto-adapts to light/dark.
